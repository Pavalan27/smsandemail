# PhishShift — AI-Powered Message Risk Scanner

**PhishShift** is a cyber-defense web application and REST API engineered to analyze incoming SMS messages, urgent text notifications, and mobile communications for social engineering, spam, and phishing threats.

By pairing a pre-trained **TF-IDF + Logistic Regression Machine Learning Classifier** with **heuristic indicator extraction** and **static URL forensics**, PhishShift calculates an intuitive 0–100 risk score and provides actionable guidance to help users avoid credential theft and fraud.

---

## ⚡ Core Features

- **Trained 3-Class Text Classifier**: Evaluates input text into three distinct categories:
  - `Legitimate`
  - `Spam`
  - `Phishing`
- **Model Confidence Breakdown**: Displays genuine probability distributions across all classes generated by `model.predict_proba()`.
- **Static URL Forensic Engine**: Extracts links without fetching or visiting them. Flags dangerous numeric IP hosts, suspicious/high-abuse TLDs, masking URL shorteners, and brand impersonation.
- **Heuristic Threat Indicators**: Identifies pressure tactics, artificial urgency, credential-harvesting phrases, prize/lottery claims, fake delivery notifications, and financial demands.
- **Composite Heuristic Risk Score (0–100)**: Blends machine learning confidence with detected forensic indicators into an animated radial gauge categorized into Low, Medium, or High risk.
- **Zero-Storage Privacy Preservation**: Messages are processed strictly in volatile server memory and never written to disk, database, or audit logs.
- **Cybersecurity Dashboard UI**: Built with a dark navy & blue-violet theme, responsive glassmorphism panels, radar scan animations, and live character/word counters.

## 🚀 Quickstart & Local Installation

### Prerequisites
- Python 3.10 or higher installed ([python.org](https://www.python.org/))
- Git (optional, for cloning)

### 1. Set Up a Virtual Environment

Open your terminal or command prompt in the project root directory:

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install Dependencies

Install the requirements into your active virtual environment:

```bash
pip install -r requirements.txt
```

### 3. Verify Model File Placement

Ensure your pre-trained model file `phishshift_3class.joblib` is placed in the root directory:

```
PhishShift/phishshift_3class.joblib
```

> **Note:** If the model file is missing or named `phishshift_3class (2).joblib`, the application automatically checks candidate filenames. If no model is found, the application starts gracefully and reports a descriptive setup error without crashing.

### 4. Run the Application

Launch the Flask development server:

```bash
python app.py
```

The terminal will display the local development URL:

```
==================================================
 PhishShift - Message Risk Scanner Server
 Running at: http://127.0.0.1:5000
 Health check: http://127.0.0.1:5000/api/health
==================================================
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your web browser to use the interface.

### 2. Scan Message
Submit a message for classification, forensic link inspection, and heuristic risk scoring.

- **Endpoint:** `POST /api/scan`
- **Headers:** `Content-Type: application/json`
- **Request Body:**
  ```json
  {
    "message": "URGENT: Your Wells Fargo account has been locked due to suspicious activity. Verify immediately at http://192.168.1.1/login-wf"
  }
  ```

#### Example cURL:
```bash
curl -X POST http://127.0.0.1:5000/api/scan \
  -H "Content-Type: application/json" \
  -d '{"message": "URGENT: Your Wells Fargo account has been locked. Verify immediately at http://192.168.1.1/login-wf"}'
```


## 🛡️ Security, Privacy & Safety Guidelines

1. **Zero Retention Policy**:
   Messages submitted to `/api/scan` are evaluated strictly in volatile RAM and immediately discarded. No messages are stored in databases, flat files, or browser storage.
2. **Sanitized Logging**:
   Server logs capture only non-identifying telemetry (timestamp, client IP, character length, predicted category, and risk score). Raw message text is **never** printed to stdout or written to log files.
3. **No External Network Calls**:
   URL analysis is strictly **static text parsing**. Links are never fetched, visited, or resolved, preventing attackers from tracking tracking-pixel clicks or triggering server-side canary tokens.
4. **Input Defense & Rate Limiting**:
   Request bodies are validated for JSON integrity and strictly capped at 10,000 characters. An in-memory sliding window rate limiter protects endpoints against volumetric abuse.
5. **XSS Immunity**:
   User input rendered dynamically on the frontend is constructed through secure DOM text properties (`textContent`), ensuring user text can never execute arbitrary scripts.

## ⚠️ Model Scope & Limitations

- **Dataset Boundary**: The machine learning model was trained on an **SMS dataset** using TF-IDF n-grams and Logistic Regression (achieving ~96.66% held-out test accuracy). It is **not** trained or validated for email headers (SPF/DKIM/DMARC), email attachments, obfuscated scripts, or binary malware payloads.
- **Probabilistic Nature**: Machine learning predictions represent statistical likelihood, not guaranteed ground truth.
- **"Legitimate" Does Not Guarantee Safety**: A message classified as "Legitimate" means its phrasing resembles typical non-malicious SMS communications. Spear-phishing or newly registered threat domains may evade text-only models. Always verify requests through official channels.
